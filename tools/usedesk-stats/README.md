# Сведения о компании в базе Usedesk

Запросы раздела 9 [плана переноса](../../docs/usedesk-migration.md) одним прогоном. Только `SELECT`: токены, пароли,
URL с ключами и персональные данные не выводятся — только счётчики, длины и короткие префиксы.

- `stats.sql` — настройки, справочники, правила, доп. поля, макросы. Быстрый.
- `stats-heavy.sql` — тикеты, сообщения, клиенты, значения доп. полей, теги, история тикетов. Таблицы в сотни
  миллионов строк: запускать на реплике или в тихие часы.

```bash
COMPANY=123   # id нашей компании в Usedesk
for f in stats stats-heavy; do
  { echo "SET @company = $COMPANY;"; cat tools/usedesk-stats/$f.sql; } |
    mysql -h <хост> -u <пользователь> -p --table --comments -vvv --force usedesk > $f.txt
done
```

`-vvv` печатает перед каждым результатом сам запрос с комментарием, `--force` не останавливает прогон на ошибке
(например, если на проде нет столбца). Результаты (`stats.txt`, `stats-heavy.txt`) — во внутренний канал, не в репозиторий.
