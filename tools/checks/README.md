# Проверки работающего стенда

Скрипты проверяют локальный стенд целиком: API, realtime, правила, Telegram, LDAP, публикацию виджета, вложения и вид админки.
Они не заменяют модульные тесты (`tests/Relayo.Tests`) — им нужны запущенные сервисы, Docker и `.env` в корне репозитория.

```bash
cd tools/checks && npm install   # один раз: playwright-core (браузер — системный Chrome) и mssql
```

Каждый скрипт печатает `PASS`/`FAIL` по шагам и в конце `ALL PASSED` или число ошибок (код выхода 1).

| Скрипт | Что проверяет | Нужно |
|---|---|---|
| `e2e.py` | Виджет → тикет → ответ, `identify`, зеркало, история | стенд, тестовый сайт |
| `settings.py` | Сайты, ключи, виджеты, код вставки | стенд |
| `realtime.cjs` | SignalR: сообщения оператору и посетителю, изоляция посетителей | стенд, `npm install` в `web/widget` |
| `query-token.cjs` | Токен посетителя в query для WebSocket | стенд |
| `rules.cjs` | API правил: проверки, история, порядок, права | стенд |
| `engine.cjs` | Движок правил: события, условия, действия, таймер, лимиты, журнал | стенд |
| `whatsapp-gateway.cjs` | WhatsApp по QR без телефона: поддельный шлюз на порту 5400 (настоящий остановить) — QR, подключение, входящие, ответ оператора, код перехода из виджета, отключение | стенд |
| `whatsapp.cjs` | Канал WhatsApp: API, пункт в виджете, переход на `wa.me/<номер>` с тестового сайта (тестовый виджет возвращается к прежним настройкам) | стенд |
| `email.cjs` | Почтовый канал: API, пароли не отдаются и зашифрованы в БД, проверка входа на поддельные IMAP и SMTP (успех, неверный пароль, закрытый порт), один ящик — один канал | стенд |
| `usedesk-import.cjs` | Импорт из Usedesk: подключение к MySQL, предпросмотр (только наша компания, без токенов), перенос сотрудников, почты, Telegram (фейковый токен отклоняется), WhatsApp, виджета; повторный импорт без дублей; уборка | `docker compose --profile usedesk up -d usedesk-mysql` |
| `telegram.cjs` | Переход в Telegram, входящие и исходящие (вебхук подделывается) | стенд |
| `ldap.cjs` | Подключение к AD, импорт, вход, блокировка | `docker compose --profile ad up -d` и засеянный Samba |
| `agents.cjs` | Агенты, группы, статусы, удаление, поля из AD | стенд, Samba |
| `publish.cjs` | Публикация виджета в S3, версии, откат, загрузка на сайте | стенд, S3 |
| `files.cjs` | Вложения: отправка посетителем и оператором, S3 и временные ссылки, отказы по типу и размеру, выключенные файлы; настройки канала, картинка кнопки, удаление виджета | стенд, S3 |
| `scale.cjs` | Два экземпляра внутреннего сервиса с Redis: realtime между экземплярами, общий лимит входа, аренда опроса Telegram. Исчерпывает лимит входа на минуту — запускать последней | второй экземпляр: `INTERNAL_HTTP_PORT=5110 INTERNAL_GRPC_PORT=5111 dotnet run --project src/Relayo.Internal --no-build` |
| `unread.cjs` | Новые обращения: счётчик во вкладке, подсветка, сброс | стенд, Chrome |
| `notes.cjs` | Внутренние заметки (не видны клиенту), страница сайта у чата, группа тикета | стенд |
| `widget.cjs` | Скриншоты виджета на тестовом сайте | тестовый сайт, Chrome |
| `shoot.cjs` | Скриншоты страниц админки: `node shoot.cjs '/agents|agents'` | админка на 5173 |
| `deploy.cjs`, `stand-s3.cjs` | Боевой стенд `deploy/` на портах 6080/6200/6300 | стенд `deploy/` |

Скриншоты сохраняются в `out/` (не коммитится).

`db.cjs` — запросы к БД стенда (MS SQL) из проверок и из терминала: `node db.cjs "SELECT COUNT(*) FROM tickets"`.
Строки печатаются как у `psql -At`: значения через `|`, id в нижнем регистре.

Вход в админку ограничен 10 попытками в минуту — не запускайте много скриптов подряд без паузы.
Скрипты создают тестовые данные с уникальным суффиксом; часть удаляет за собой сама, остальное убирается вручную.
